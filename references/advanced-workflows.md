# 高级工作流

## 产品目录

用 `new-catalog-job.ps1` 把商品列表转换为普通 `jobVersion: 1` 任务。目录适配器只负责复制画板、填入三类文字和嵌入商品图；工作副本、预览、提交和重开复验仍由公共两步管线完成。

## 大型 PSB

PSB、大于 1 GB、超过 20 个画板或极大画布仍使用文件系统工作副本。保持一次打开、一次保存、一次重开；不要 `Document.duplicate()` 整份大型文档。超时后先读取当前文档和文件状态，不要重放修改。

## 最终输出

`outputs.final.type` 支持：

- `document-jpg`：提供 `path`、`maxWidth`、`quality`。
- `artboards`：提供 `outputDirectory`、精确 `artboardNames` 顺序、`format`、`maxWidth`、`quality`。

目标存在时，只有任务明确设置 `overwriteExistingOutputs:true` 才覆盖。

## 叮咚详情页、主图与已使用图片整包导出

当用户说“导出某路径的图片”时运行：

```powershell
.\scripts\export-dingdong-image-package.ps1 `
  -ProductDirectory D:\商品目录
```

统一入口固定执行：

1. 只检查指定目录根层的 PSD/PSB，并通过当前文档结构唯一识别详情页和主图；详情页必须是无画板的纵向文档且带有效水平参考线，主图必须恰好包含画板 `0`–`7`。不得按文件名、母版名或目录名猜测；任一角色不唯一就停止并列出候选结构。
2. 详情页固定先导出一张原画布尺寸、质量 10 的 `详情页长图.jpg`，再只读取指定目录内当前商品详情 PSD 自己保存的水平参考线。以当前画布顶部 `0`、每条有效内部水平参考线和当前画布底部组成连续全宽切片；禁止读取母版、模板定义、模板索引、历史导出记录、固定高度或母版参考线作为回退。没有有效内部水平参考线时停止。
3. 主图按精确名称 `0`–`7` 依次逐画板导出 JPG；画板 `0` 必须包含在整包导出中。
4. 把详情页长图与切片、八张主图和指定目录 `已使用` 文件夹内的 JPG/JPEG/PNG/WEBP 复制到临时打包目录。商品目录根层如有基础名精确为 `白底图` 或 `标签` 的 JPG/JPEG/PNG/WEBP，或精确文件名 `包装图.jpg`、`白标.jpg`，每类只允许一个，先以相同文件名和 SHA-256 复制到 `主图/`；同类多文件或不支持格式立即停止。完整导出后在商品目录内保留 `<商品目录>\未压缩图片-yyyyMMdd-HHmmss\详情页|主图|已使用`，该目录不压缩、不打包且在后续阶段必须保持哈希不变。
5. 只对临时目录中的 `详情页/` 和 `主图/` 实际调用 `D:\谷鱼视觉\小梅园\images\image-compressor.exe --target-kb 600 --recursive --no-pause`，核对压缩器报告的处理数量。只有无法达到目标体积的 `[WARN]` 可以继续；任何 `[ERROR]`、处理数量不一致或 `已使用/` 副本哈希变化都停止。
6. 从未压缩输出的临时副本生成真实 7z，验证 `详情页/`、`主图/`、`已使用/` 的文件头、归档清单和哈希后，把压缩包放到 `D:\谷鱼视觉\小梅园`。默认文件名为 `<商品目录名>-图片-yyyyMMdd-HHmmss.7z`；不得覆盖同名压缩包，除非当前请求明确要求覆盖。

该入口把“导出某路径的图片”视为对本次读取 PSD、生成临时导出图、压缩临时副本和创建新 7z 的完整授权，不再逐步询问；它不授权修改 PSD、压缩原始素材、删除产品文件或覆盖既有压缩包。

## 素材整理

普通任务默认关闭。叮咚七图主图使用正式详情页作为图片来源时默认强制启用，并在主图提交、重开验证后由同一次完成调用立即执行。普通任务手动启用时填写：

```json
{
  "organizeUsedAssets": {
    "psdPath": "D:/商品/详情页.psd",
    "workDir": "D:/商品",
    "journalPath": "D:/商品/.used-assets-journal.json"
  }
}
```

只处理工作目录根层、被 PSD 可见智能对象实际引用的图片。扫描前必须临时激活指定 PSD，读取完成后恢复先前活动文档，避免图层遍历目标与智能对象描述读取目标不一致。相同哈希才删除重复源；不同内容改名移动到 `已使用`。journal 支持中断恢复，整理失败不回滚已提交 PSD。叮咚主图的七项来源映射只决定主图取图，不是详情页素材整理范围；生成的主图任务不得写入 `sourceLayerIds`，完成脚本也必须忽略旧任务遗留的该过滤器。已有完成 journal 的筛选范围与本次请求不一致，或 journal 错误记录为零个可见智能对象时，先归档旧 journal，再按新范围重扫；新的零对象扫描必须报错，不能写成完成。
