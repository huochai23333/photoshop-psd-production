# 叮咚文案参考句库

## 使用与维护

拟写或重写前，与文案规则一起读取本文件。先按当前食材、板块用途和卖点选择已认可的句子；所涉事实吻合且适合当前位置时，直接沿用原句。需要补充内容时，再学习参考句的表达关系来拟写。

例句提供表达，当前商品资料提供事实证据。只核对所选句实际涉及的产地、配料、部位、克重、口感或烹饪时间；事实吻合即可复用原句，无需为了原创另换说法。事实不符或尚未确认时，处理受影响的内容，其他已经成立的句子仍可沿用。参考句库保持现有保护范围、固定文字和板块禁写限制。

选句顺序：

1. 先选用户逐句认可的完整文案、适用的甲方指定文案，再选用户认可参考图中的完整句组。按用途匹配，同类食材只是线索，还需核对句中具体事实。
2. 原句的事实、板块用途和现有版面要求均满足时，直接使用原句，保留其自然搭配与节奏。
3. 仅有局部不适用时，只调整该局部。例如配菜变化应调整相关配菜描述，仍然成立的牛肉部位、质地及口感描述继续沿用。
4. 没有合适的完整句子时，才为对应空缺位置拟写。用户只认可局部短语的，按局部参考使用，不能据此接受此前被否定的整句。

用户说“把这句加进参考”“这句话不喜欢，记下来”时，在相应表中追加原句、场景、理由和评价来源。只有用户给出或确认的理由才记为用户偏好；AI 的分析标为观察或待确认。仅有一次修改不自动升级为全品类禁词。若用户只评价好坏，保留其评价，理由记为“尚未说明”，不要替用户编造。

默认只读取，用户明确要求增删或修订句库时才更新。不要把评语、反例标签或讨论过程写进商品成稿。

甲方或用户明确指定的文案按确认字样保留，记录来源与适用场景。
