# 详情页整页重复检查

拟稿时对照当前页面全部可见文字，不仅对照本次可改目标。未修改、固定或受保护的文字也参与比较，但参与检查不代表允许改动。

## 程序执行位置

- `prepare-psd-job.ps1` 读取实际来源 PSD，合并 `textReplacements` 和计划显隐状态，检查通过才创建工作副本。
- `Invoke-PsdJobApply` 在首个图层修改前，用真实工作副本再次执行相同规则。直接调用写入函数、使用 `generic` 或临时兼容模式，也不能绕过具有详情页板块结构的文档检查。
- `complete-psd-job.ps1` 在覆盖正式文件前检查已保存工作副本，防止旧运行记录将重复内容提交。结果保存在现有 `run.json` 的 `pageCopyValidation` 和准备结果中，不创建独立审批文件。

按真实父子关系计算可见性；隐藏父组或透明祖先下的文字不计入输出。计划显示的文字计入，计划隐藏的文字排除。检查实际图层内容，不依赖可能过期的模板索引。使用至少两个“头版／版N／尾版”分组识别详情页，不能通过任务模式声明关闭；主图跨画板的正常同步不作为详情页跨板块重复。

程序比较各文字层全文、显式行及句末分隔的完整句，忽略空白、换行和标点。规范化后至少 8 个字符且包含至少 6 个汉字的完整句，在不同板块出现即以 `duplicate-page-copy` 阻止写入，报告双方板块、图层 ID 和重复原文。现行头版 ID 10 的完整正式品名允许精确复现；短词、品牌装饰不按长句重复处理。同义重复、较短关键词的复用次数及非相邻要求继续做语义审稿；图像或智能对象内部的烘焙文字仍通过预览核对，程序不冒充 OCR 或自然度判断。

只读检查当前商品或计划结果：

```powershell
.\scripts\test-psd-page-copy.ps1 -DocumentPath 'E:\商品\详情页.psd'
.\scripts\test-psd-page-copy.ps1 -DocumentPath 'E:\商品\详情页.psd' -TaskPath 'C:\工作\detail-job.json'
```

## 发现重复后的处理

先保留受保护、固定和本次未授权的文字，调整允许修改位置的候选，再检查整页。初稿阶段处理好再出稿；已确认稿需要改字时，展示修改后的完整两列表并重新确认，旧稿、哈希及任务随之失效。程序只阻止错误写入，不自动改文案、隐藏图层、缩字或扩大编辑范围。

不确定某句参考文案或卖点是否可用时，通过 Codex 提问弹窗集中询问：写清候选原句及存疑内容，提供简短选项并允许用户补充。优先使用可用的 `request_user_input_async`；若环境仅提供可用的 `request_user_input`，使用该工具。只有环境没有可用弹窗工具时才用普通消息提问。已确认内容不重复问，未收到答复不得将默认选项视为认可，也不将问题附在正式文案表中。
